# Anna — GE110 สรุปบทเรียน บทที่ 5–8

สรุปวิชา GE110 วิทยาศาสตร์และเทคโนโลยีในชีวิตประจำวัน บทที่ 5–8 (เครื่องสำอาง · สุขภาพและการออกกำลังกาย · เครื่องนุ่งห่ม · ที่อยู่อาศัย) พร้อมแบบทดสอบบทละ 30 ข้อ

- `สรุป-บทที่*.md` — ไฟล์สรุป (รูปสไลด์อยู่ใน `img/`)
- `quiz-บทที่*.html` — แบบทดสอบ เปิดในเบราว์เซอร์ได้เลย
- `docs/` — เว็บไซต์ (GitHub Pages) สร้างด้วย `python build.py`
